# 🏋️ Workout Tracker (筋トレ記録・管理アプリ)

直感的なUIで日々の筋トレのセット数や重量を記録・管理できるWebアプリケーションです。

## 🌐 アプリURL
https://resilient-gecko-baa54e.netlify.app/
※どなたでもブラウザから実際に触って動かすことができます。

## 💡 開発の背景と目的
自身が筋トレを行う中で、既存のメモ帳アプリでは「過去の重量の振り返り」や「セットごとの記録」が煩雑になるという課題を感じていました。その不便さを解消し、シンプルに記録・管理ができるツールを作るために開発しました。

## 🛠 使用技術
- **フロントエンド:** React, Vite, JavaScript
- **スタイリング:** CSS
- **ホスティング・デプロイ:** Netlify

## ✨ 工夫した点・主な機能
- **アジャイルな機能追加:** 友人にテスト利用してもらったフィードバックをもとに、「誤入力時のデータ削除・修正機能」などの必要な機能を後から追加実装しました。
- **レスポンシブ対応:** ジムでの利用を想定し、スマートフォンからでも見やすいUIを実装しています。
- **AIの活用:** 開発の過程で生成AI（ChatGPT等）を壁打ち相手として活用し、エラーの特定やロジックの修正を効率的に行いながらシステムを完遂させました。
